# Nuxt module

`@orbisk/vue-use-barcode-detection/nuxt` registers the composable as an auto-import and the scanner + overlay as global components, so you can drop them anywhere in your Nuxt app without importing.

## Setup

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@orbisk/vue-use-barcode-detection/nuxt'],
})
```

That's it — no options to configure.

## What you get

- **`useBarcodeDetector`** — auto-imported composable. See [`useBarcodeDetector`](/functions/use-barcode-detector) for the full reference.
- **`<UseBarcodeDetector />`** — drop-in scanner component, registered globally.
- **`<BarcodeDetectorOverlay />`** — standalone SVG overlay drawing accepted (green) and rejected (red) barcode polygons. Registered globally.
- **`<UBarcodeInput />`** — opt-in input field paired with a scan button. Only registered when [`@nuxt/ui`](https://ui.nuxt.com) is present in your app. See the [Nuxt UI integration](/nuxt/nuxt-ui) page for the full reference.

## Usage

```vue [pages/scan.vue]
<template>
  <UseBarcodeDetector v-slot="{ start, stop, isActive, detected }">
    <button @click="isActive ? stop() : start()">
      {{ isActive ? 'Stop' : 'Start camera' }}
    </button>
    <ul>
      <li v-for="b in detected" :key="b.rawValue">
        <strong>{{ b.format }}</strong> — <code>{{ b.rawValue }}</code>
      </li>
    </ul>
  </UseBarcodeDetector>
</template>
```

No imports needed — the composable and components are auto-registered.

## Polyfill on the client

To support browsers without a native `BarcodeDetector` (Firefox, Safari, desktop Linux Chromium), drop in the [`barcode-detector`](https://www.npmjs.com/package/barcode-detector) polyfill from a client plugin:

```ts [plugins/barcode-detector.client.ts]
export default defineNuxtPlugin(async () => {
  if ('BarcodeDetector' in window) return
  await import('barcode-detector/polyfill')
})
```

The conditional import keeps native implementations winning where they exist.
